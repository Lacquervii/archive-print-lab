# Reference analysis and abstraction

## Goal

Extract what can travel to a new task while discarding source-specific inventory.

## Evidence ledger

Before prompt assembly, record:

| Question | Evidence | Confidence | Transferable? |
|---|---|---|---|
| Viewer action? | | high/medium/low | yes/no |
| Subject behavior? | | | |
| First attention? | | | |
| Reading order? | | | |
| Scale contrast? | | | |
| Crop / overlap behavior? | | | |
| Scale ladder / weight steps? | | | |
| Image/material treatment? | | | |
| Crisp structural layer? | | | |
| Density and quiet zones? | | | |
| Color role? | | | |
| Typography role? | | | |
| Finish / carrier? | | | |
| Source-specific inventory to discard? | | | no |

## Abstraction test

Write a one-sentence abstraction with no proper nouns, no object names, no exact title, no exact color, and no unique symbols:

```text
[carrier] with [first-attention structure], [hierarchical subject/information cluster], [layer relationship], [semantic structural carriers], [density rhythm], and [finish]
```

If the sentence still names “flower,” “book,” “hand,” “purple,” “CHANHUA,” a particular logo, or an exact frame system, it is not abstract enough.

## Reference roles

- **Benchmark:** teaches relationships only.
- **Base image:** may be preserved or edited; requires explicit user intent and rights awareness.
- **Material reference:** teaches surface, light, or process.
- **Content reference:** supplies factual subject matter; do not silently convert it into style.
- **Case study:** documents a successful or failed adaptation for future diagnosis.

## Anti-overfitting checks

Before generation ask:

1. Could the subject block be swapped for another subject without rewriting the design engine?
2. Did any source title, object inventory, icon, frame, or palette leak?
3. Is the selected recipe justified by the carrier and brief?
4. Are structural marks caused by the current subject or information task?
5. Would a human designer recognize a new authored work rather than a reskin?

## Benchmark discipline

Study first attention, type-image contact, image operations, material continuity, local density, quiet zones, and reading distance. Do not average references into a moodboard. Do not copy a source grid, font, color, logo, or signature motif unless the user explicitly requests recreation.
