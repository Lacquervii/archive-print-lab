# Output contract

## Prompt delivery (default)

Return the fixed family engine, selected mode and recipe, internal surface choice, compiled theme proposition, palette rationale, title fit, carrier provenance, and one ready-to-use prompt (in the user’s language unless they asked for English). Keep exact text short and state that lettering depends on the generator.

## Generation (when the user renders)

Return:

- inline image (when rendering succeeded);
- selected ratio and ratio source;
- generator, requested size, actual returned size, and exact/near-match/mismatch status;
- selected mode, recipe, chassis intensity, and surface branch;
- image and prompt links;
- concise honest review against the canonical skeleton or explicit mode override.

If no generator is available in the current environment, say so and deliver the prompt plus the exact parameters the user would need elsewhere.

Never report a requested size as the returned size. Never claim exact text or geometry when the pixels do not support it.

## Iteration

Name the top one or two failures and change only the corresponding prompt/composition blocks before regenerating the prompt.

## Skill optimization

Report the package changes and validation result. Do not generate an image unless the user separately asks for one.
