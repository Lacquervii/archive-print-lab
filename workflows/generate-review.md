# Workflow: compile a prompt, optionally render, and review

## Before writing the prompt

1. Confirm viewer action, subject behavior, carrier, ratio (`16:9` by default; latest explicit user ratio otherwise), named generator if any, reference role, exact-text requirement and exclusions.
2. Load `family-standard.md`, `aspect-ratio-contract.md`, and `canonical-layout-spec.md`. Unless the brief explicitly requests hero, material, process, archive, narrative, information or quiet behavior, select the canonical series cover: `concentrated_cover` + `concentrated editorial cover` + `structural` chassis + selected ratio.
3. If an alternate mode is explicit, record the override and its allowed chassis reduction; do not silently mix the alternate recipe with canonical-cover claims.
4. Compile the theme with `theme-compiler.md` and `theme-customization-contract.md`: proposition, complete gestalt, related supports, 1–2 meso events, material proof, theme/carrier/profile provenance, fresh adaptation delta and palette record, and a short refusal list.
5. Plan the page using the default 16:9 zones from `canonical-layout-spec.md`, or derive equivalent zones when the latest brief explicitly overrides the ratio: macro/title fit, bounded central envelope, meso field, contact matrix, chassis members, protected corridors, release and layer order. Store internal records using `compiled-theme.schema.json`, `composition-plan.schema.json` and `series-contract.schema.json` when structured tracking helps.
6. Read `rendering-branches.md` and resolve the rendering-style branch **before writing any prompt**. If the latest brief did not explicitly select or carry one over, ask the compact branch question and wait. A user saying `随你` permits the documented recommendation; a theme noun never silently selects warm analog print.
7. If the named generator is Image2 / gpt-image-2, load `image2-editorial-adapter.md` in addition to `structural-scale-ladder.md` and `editorial-imprint.md`; restore the Image2 pressure profile without changing the generator-neutral family contract.
8. Render the prompt using `prompt-renderer.md`: canonical or override preflight → selected canvas / ratio instruction (default 16:9; concrete size only when a generator is named) → macro → complete central gestalt → meso events → resolved chassis contacts → release and small series imprint → selected branch surface clause → theme material/palette/finish → short branch-specific and strong-prior exclusions. Do not send a module menu, audit vocabulary, quotas or a massive negative list to the model.
9. Run anti-overfitting, canonical-series-fit or override-fit, mode-fit, rendering-style-branch fit, chassis-translation, footprint and carrier checks.

## Delivery

1. Deliver the compiled prompt. This is the default output of the Skill and requires no generator.
2. If the user named a generator and rendering is possible in the environment, inspect actual pixels and actual output dimensions at thumbnail, normal and close distance; run the selected-ratio test before any beauty review.
3. Compare returned dimensions to the selected ratio only when an image was actually rendered; report exact, near-match or mismatch. Deliver the rendered file as generated; do not normalize it in a second route. If no rendering happened, simply report that the deliverable is the prompt.

## Review (applies to the prompt itself and to any rendered image)

1. Compare first attention, central footprint, protected corridors, canonical series skeleton or explicitly recorded mode override, selected mode, recipe, chassis pressure, macro/meso/subject/micro contact, material, palette, typography and finish.
2. Check source leakage, copied profile inventory, fake factual annotation, generic HUD drift, silent inherited palette/title/graphic ink, missing palette derivation or forbidden-hue block, **unselected rendering-style leakage** (for example retro warmth under `contemporary_frosted`), and text expectations.
3. Classify pass, revise or fail. Diagnose the top issue as routing, series contract, recipe, compiler, composition, chassis, carrier, theme, material, palette, generator adaptation or delivery.
4. Change only the first one or two failed blocks; do not repair a routing/composition failure by adding adjectives or more negatives.
5. Copy prompt, optional rendered output, compiled-theme record, composition plan, series contract and review notes to archive.
6. Report the requested and returned dimensions only when rendering happened, plus honest generator text/geometry limitations.
